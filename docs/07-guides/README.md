# 07 — Guides

Guides explain normal, repeatable procedures.

- [Playbook 1 — Project from zero](project-start-playbook.md) — human-led discovery, requirements, architecture and the first tested vertical slice (proposed for review).
- [Playbook 2 — Feature development](feature-development-playbook.md) — human-led impact analysis, just-enough design, implementation, tests and PR review (proposed for review).

Examples:

- local development;
- adding a provider;
- database migrations;
- deployment procedure;
- contributor workflows.

Guides may point to Standards but should not silently invent new normative rules.
