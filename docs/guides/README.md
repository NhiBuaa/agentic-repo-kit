# Guides

This directory contains normal development and operational procedures.

Create a Guide when contributors repeatedly need to know how to perform a routine task.

Examples:

- local development setup;
- adding a provider or integration;
- creating a database migration;
- releasing a version.

A Guide explains how to perform a normal procedure. It should reference Standards rather than redefine normative rules.

For abnormal operational states, recovery, or incident response, use `docs/runbooks/` instead.

Starter template: `templates/guide.md`
