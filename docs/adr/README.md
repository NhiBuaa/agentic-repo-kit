# Architecture Decision Records

This directory preserves the rationale for significant architectural decisions.

Create an ADR when a decision:

- has meaningful alternatives;
- affects architecture, boundaries, or long-term constraints;
- has consequences worth preserving;
- may be difficult or costly to reverse.

Do not create ADRs for trivial implementation choices or task progress.

Suggested naming:

```text
0001-short-title.md
0002-short-title.md
```

Recommended statuses:

- Proposed
- Accepted
- Superseded

Starter template: `templates/adr.md`
