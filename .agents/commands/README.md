# Agent Commands

Store repository-local command definitions or explicit workflow entrypoints here.

Use this area for repeatable actions that a human or agent may invoke intentionally, for example repository-specific review, release, migration, or maintenance commands.

Commands may orchestrate existing skills, scripts, checks, or documentation, but they must not become a second source of project truth.

Keep tool-specific syntax in the relevant adapter when necessary; this directory owns the repository-level intent of a command, not vendor-specific loading behavior.
