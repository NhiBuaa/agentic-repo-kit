# Reviews

This directory contains retained code, architecture, security, or design review findings.

Create a Review artifact when findings should survive beyond a transient PR conversation or when a structured review output is useful for follow-up work.

A Review may contain:

- reviewed scope and revision;
- findings by severity;
- verification gaps;
- positive evidence where useful;
- recommendation for acceptance or remediation.

Authority: findings only.

A review finding is not automatically an accepted architectural or normative decision. If a finding becomes durable truth, promote it into the appropriate Architecture, Standard, ADR, or Specification.

Starter template: `templates/review.md`
