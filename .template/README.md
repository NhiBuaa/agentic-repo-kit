# Template Scaffolding

This directory contains optional starter files for artifact classes that should be created only when a real project need appears.

The repository operating system does not depend on this directory.

You may:

- keep it as a scaffolding library;
- move it to an external template repository;
- delete it after project bootstrap.

Available starters:

```text
artifacts/
├── architecture.md
├── standard.md
├── adr.md
├── spec.md
├── guide.md
├── runbook.md
├── plan.md
├── handoff.md
├── review.md
└── evidence.md
```

Create the corresponding canonical directory only when needed.
