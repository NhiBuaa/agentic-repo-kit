# Agentic Repo Kit

## Positioning

Agentic Repo Kit is a reusable, vendor-neutral repository operating system for software projects developed with coding agents.

It defines clear ownership for:

- agent instructions;
- durable architecture and standards;
- current project context;
- specifications and decisions;
- task-local plans, handoffs, reviews, and evidence.

## Design Goal

High context quality with low context volume, clear authority, low duplication, low staleness, and cross-agent portability.

## Current Stage

Version `0.1` — architecture and template design.

The project may evolve into an open-source toolkit in the future, but the current repository remains focused on validating the core repository model before adding automation or tooling.
